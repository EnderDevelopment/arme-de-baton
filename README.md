# Armée de Bâton

Armée de Bâton est un plugin Minecraft qui permet de créer et contrôler une armée de mobs avec un bâton de commandement. Ce plugin est conçu pour les serveurs Minecraft Bedrock et offre une expérience de jeu immersive en permettant aux joueurs de contrôler leurs mobs comme une armée.

## Install

1. Téléchargez le fichier JAR du plugin.
2. Placez le fichier JAR dans le dossier `plugins` de votre serveur Minecraft.
3. Redémarrez votre serveur Minecraft.

## Use

1. Connectez-vous à votre serveur Minecraft.
2. Utilisez la commande `/givecommandstick` pour obtenir un bâton de commandement.
3. Cliquez avec le bâton de commandement sur un mob pour le contrôler.
4. Utilisez les commandes spécifiques du plugin pour créer, déplacer et dissoudre votre armée de mobs.
